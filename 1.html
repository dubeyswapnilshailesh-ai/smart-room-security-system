PROJECT INFORMATION

About Sentinel

Smart Room Security System — conditional circuit demonstration.

Project Overview

This mini-project demonstrates a smart room security system using conditional logic. The operator can simulate the armed state, door position and password verification, then observe the alarm and access-granted outputs.

Input Signals

  • system_armed: Enables security monitoring.
  • door_open: Represents the door sensor state.
  • password_ok: Represents password verification.

Output Rules

  • Armed + door open + correct password → access_granted = 1, alarm = 0.
  • Armed + door open + wrong password → alarm = 1, access_granted = 0.
  • System disarmed or door closed → both outputs = 0.

Technology

HTML, CSS and JavaScript provide the interactive dashboard. The logic mirrors the Verilog demonstration, but this webpage does not run the Icarus Verilog simulator directly.
